# 100 Days of Python 🐍

This repository documents my progress as I develop my Python programming skills through the 100 Days of Code course.

Rather than simply completing lessons, my goal is to build a strong foundation in Python, improve my problem-solving ability, and gradually apply what I learn to independent software projects.

## What I'm Learning

Throughout the course, I am developing my understanding of:

- Python fundamentals
- Functions and modules
- Object-Oriented Programming (OOP)
- Error handling
- File handling
- Working with external data
- Building graphical applications
- Problem solving and program design
- Git and GitHub

## Projects

Some of the projects I have built during my learning journey include:

- Coffee Machine
- Quiz Game
- Hirst Painting
- Snake Game
- Pong
- Crossy Road

Each project has helped me practise different Python concepts and apply them in increasingly complex programs.

## Beyond the Course

Alongside the course, I am beginning to:

- Build independent Python projects
- Practise coding problems and data structures
- Improve my use of Git and GitHub
- Develop stronger software engineering habits

My aim is to move beyond following tutorials and become increasingly confident designing and building software independently.
